# Reuniones

Cada reunión tendrá un archivo con:

- fecha;
- participantes;
- temas tratados;
- decisiones tomadas;
- requisitos confirmados;
- preguntas nuevas;
- cambios respecto a decisiones anteriores;
- acciones y responsables.

Los acuerdos del RNC deben convertirse posteriormente en requisitos o decisiones con identificadores estables.
