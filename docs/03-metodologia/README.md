# Metodología epidemiológica

Aquí se documentarán las definiciones y fórmulas que gobiernan el motor estadístico.

Cada concepto debe incluir:

- definición;
- fórmula;
- significado epidemiológico;
- entradas requeridas;
- supuestos;
- ejemplos;
- tratamiento de casos límite;
- fuente primaria;
- decisión específica del RNC, cuando exista.

No implementar fórmulas como reglas del RNC hasta que estén respaldadas por una fuente apropiada o validadas por el especialista correspondiente.
