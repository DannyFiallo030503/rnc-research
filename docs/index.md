# Índice del conocimiento del proyecto RNC

## Primeros archivos que leer

1. `../PROJECT_CONTEXT.md` — contexto vivo para continuar el proyecto desde otro chat o IA.
2. `00-estado-investigacion.md` — situación actual y prioridades.
3. `00-criterio-investigacion.md` — reglas para investigar y clasificar evidencia.
4. `evidence-map.md` — trazabilidad de afirmaciones.
5. `../sources/catalogo.md` — catálogo maestro de fuentes.

## Áreas

1. `01-negocio/` — funcionamiento del registro, estadísticas cubanas y calidad.
2. `02-benchmark/` — sistemas reales, publicaciones y estudios comparativos.
3. `03-metodologia/` — tasas, estandarización, intervalos y metodología epidemiológica.
4. `04-ux-ui/` — usabilidad, accesibilidad y visualización.
5. `05-requisitos/` — preguntas abiertas y futuros requisitos/reglas.
6. `06-arquitectura/` — arquitectura y artefactos de ingeniería cuando el dominio esté suficientemente cerrado.
7. `07-decisiones/` — decisiones formales.
8. `08-reuniones/` — acuerdos reales obtenidos con el RNC y tutores.

## Regla central

Nunca pasar directamente de "otro sistema lo hace" a "el RNC debe hacerlo".

Usar:

**fuente → evidencia → interpretación → propuesta → validación con RNC → requisito/regla → implementación → prueba**.
