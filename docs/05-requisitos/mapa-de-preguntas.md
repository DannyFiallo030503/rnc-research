# Mapa de preguntas para validar con el RNC

Estado: cotejado con Manual RNC VII (revisión íntegra del PDF 2026-10-13), Yinet (2026-09-30), aclaraciones del estudiante (2026-10-06) y fuentes públicas cubanas

Corte: 2026-10-13

Las preguntas son huecos de conocimiento, no requisitos. El manual y la aclaración escrita responden algunas; esas respuestas no cierran decisiones de interfaz, arquitectura o publicación que no tratan.

Para preparar la siguiente reunión, usar el [documento Word actualizado](detalles-pendientes-actualizado-2026-10-06.docx) o la [versión Markdown](detalles-pendientes-para-requisitos-y-diseno.md). El Word sin fecha conserva el guion anterior.

## Regla de uso

Una pregunta solo se cierra si la evidencia responde el detalle que necesita la decisión. No inferir fórmulas o políticas de publicación a partir de que el manual solo nombre un indicador o principio.
