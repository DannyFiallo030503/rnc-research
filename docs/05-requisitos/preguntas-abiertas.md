# Preguntas abiertas del proyecto

El mapa actualizado está en `mapa-de-preguntas.md`.

Este archivo se conserva como punto de entrada para evitar romper referencias anteriores.

Antes de convertir una propuesta en requisito definitivo, revisar siempre el mapa y confirmar si la pregunta ya fue respondida por:

- documentación vigente del RNC;
- normativa cubana;
- una decisión explícita de los especialistas;
- una fuente externa que solo sirva como evidencia, pero no como regla.
