# DEC-003 — No cerrar el stack tecnológico antes del análisis

Estado: PROPUESTA
Fecha: 2026-09-09

## Decisión

No fijar todavía frontend, backend, motor estadístico ni base de datos.

## Motivo

El Anexo exige comparar alternativas y seleccionar posteriormente las tecnologías. Además, todavía faltan decisiones del dominio epidemiológico y del volumen/uso real del sistema.

## Consecuencia

Primero se estabilizan negocio, requisitos, datos y criterios de evaluación. Después se selecciona el stack.

`SRC-RNC-001`, `SRC-RNC-002`.
