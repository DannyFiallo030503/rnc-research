# DEC-004 — Trazabilidad de evidencia

Estado: PROPUESTA
Fecha: 2026-09-09

## Decisión

Toda afirmación relevante, patrón adoptado o descarte debe apuntar a una fuente mediante un ID estable.

## Motivo

Evita mezclar reglas del RNC con recomendaciones externas, opiniones del equipo o prácticas de otros registros.

## Convenciones

- `SRC-*`: fuentes.
- `EVD-*`: afirmaciones respaldadas.
- `REQ-*`: requisitos.
- `RN-*`: reglas de negocio.
- `DEC-*`: decisiones.
- `Q-*`: preguntas abiertas.
