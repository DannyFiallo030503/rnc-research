# SEER / SEER*Explorer

Estado: EVIDENCIA

## Qué aporta

SEER documenta sus definiciones estadísticas y permite explorar indicadores mediante dimensiones epidemiológicas. La plataforma SEER*Explorer proporciona exploración interactiva, tablas y visualizaciones.

## Lecciones potencialmente reutilizables

- filtros alineados con preguntas epidemiológicas;
- metodología estadística accesible desde el producto;
- combinación de tabla y visualización;
- posibilidad de descargar resultados.

## Riesgos de copiarlo sin adaptación

SEER responde a su propio modelo de datos y metodología estadounidense. No debe utilizarse como autoridad para definir la población estándar, clasificaciones o reglas del RNC cubano.
