# Proceso del registro y calidad de datos

Estado: EVIDENCIA

## Evidencia disponible

Documentación histórica de registros cubanos publicada en el contexto de IARC/Cancer Incidence in Five Continents describe flujos que incluyen fuentes hospitalarias, certificados de defunción y laboratorios, seguidos por comprobaciones de completitud/consistencia, codificación ICD-O, detección de duplicados y consolidación.

Esto debe considerarse una referencia histórica/comparativa, no una especificación vigente del RNC.

Fuente principal: `SRC-IARC-CUBA-001`.

## Implicación para el sistema

La plataforma debe considerarse una capa de explotación y difusión de información epidemiológica que ya ha atravesado un proceso de generación y control de datos. La arquitectura futura deberá contemplar trazabilidad, calidad y metadatos, aunque las reglas concretas deben ser validadas con el RNC.
