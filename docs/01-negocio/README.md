# Negocio

## Objetivo

Construir el conocimiento del funcionamiento del Registro Nacional del Cáncer de Cuba antes de fijar requisitos o tecnología.

## Fuentes prioritarias

1. Documentación oficial del RNC de Cuba.
2. Manual de Procedimientos RNC, versión VII (2024), revisado: `06-manual-procedimientos-2024.md`.
3. Otras normativas oficiales cubanas.
4. Publicaciones del propio RNC y organismos de salud.
5. IARC/WHO y estándares internacionales.
6. Documentación oficial de registros de otros países.
7. Artículos científicos y tesis como evidencia complementaria.

## Regla

Una práctica de otro registro no se convierte automáticamente en una regla del RNC cubano.
