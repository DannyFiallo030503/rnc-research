# Lecciones de UX/UI y accesibilidad

Estado: EVIDENCIA

## Hallazgo: problemas documentados de usabilidad

Un estudio de un sistema de registro de cáncer reportó problemas relacionados con falta de orientación, dificultad para relacionar tareas con controles y falta de comprensión del flujo. Los autores recomiendan guiar al usuario, alinear controles con su modelo mental y proporcionar feedback.

Fuente: `SRC-UX-001` — https://pmc.ncbi.nlm.nih.gov/articles/PMC9887869/

## Hallazgo: accesibilidad

Experiencias recientes de registros de cáncer muestran que dashboards con visualizaciones deben considerar teclado, contraste, tipografía y tablas para ampliar el acceso.

Fuentes: `SRC-CO-001`, `SRC-WCAG-001`.

## Principio para el RNC

La visualización debe complementar, no sustituir, los valores tabulares y la información metodológica.
