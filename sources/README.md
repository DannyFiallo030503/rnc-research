# Fuentes

`sources/catalogo.md` es el inventario maestro.

## Regla

Una fuente nueva debe:

1. recibir un `SRC-*` único;
2. indicar autor/organización, título, fecha de consulta y URL o ubicación;
3. registrar si es oficial, científica, tesis, proyecto o evidencia técnica;
4. indicar su autoridad y estado;
5. ser citada en el documento donde se utiliza.

Las copias locales de originales solo deben incluirse cuando sean necesarias para reproducibilidad y su redistribución sea apropiada.
